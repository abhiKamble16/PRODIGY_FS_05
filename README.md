# PRODIGY_WD_05 – Social Media Platform

## Prodigy InfoTech Web Development Internship – Task 05

A simple full-stack social media platform developed using the MERN stack.

The application allows users to create profiles, create posts, upload images/videos, like and comment on posts, and use hashtags for tagging.

## Features

- User Registration & Login
- JWT Authentication
- User Profiles
- Edit Profile
- Create Posts
- Image Upload
- Video Upload
- Like / Unlike Posts
- Comments
- Hashtag Tagging
- Social Media Feed
- MongoDB Atlas Database
- Cloudinary Media Storage
- Responsive UI

## Tech Stack

### Frontend

- React.js
- Vite
- Tailwind CSS
- Axios

### Backend

- Node.js
- Express.js
- Mongoose
- JWT
- bcrypt

### Database

- MongoDB Atlas

### Media Storage

- Cloudinary
